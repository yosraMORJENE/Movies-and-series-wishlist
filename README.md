🎬 Movie & Series Watchlist App

A native Android application developed in Kotlin for a university mobile development project.
The application helps users manage movies and TV series by tracking watched content, favorites, ongoing series, and episode progress.

📱 Features
Add and manage movies and TV series
Mark content as watched or favorite
Track ongoing series and last watched episode
Episode progress tracking with automatic completion detection
Weekly notifications for new episode release days
Personal reviews and notes system
Dynamic movie lists using RecyclerView
Motivational quotes fetched from an external API
Local SQLite database persistence
⚙️ Technologies Used
Kotlin
Android Studio
RecyclerView
ViewBinding
SQLiteOpenHelper
Retrofit (REST API integration)
AlarmManager & BroadcastReceiver
Material Design Components
🗂️ Architecture

The project follows a modular MV-style structure with separation between:

Activities
Adapters
Models
Database helper
Notifications system
🎓 Academic Context

This project was developed as part of a university mobile development course to demonstrate:

Android native development
Local database management
API integration
Notifications handling
Modern Android UI design
Multi-activity architecture
